# Business

## Who pays, what is sold

Nobody pays: MIT, free and open. The first user is the author. Publishing
carries no support commitment.

## Goals

Rough aspirations, no dates.

- G1 (about 3 months): a proven, improved repository that serves any project in any language, with results that are efficient, cheap, fast and of quality.
- G2 (about 12 months): the author's own tool, published, for the four tools.
- G3 (about 36 months): other developers install it and use it without the author's help, in the four tools.

## Not done

Marketing skills or any skill outside the flow; changes to the reference
project; indexing past chat sessions; stack skills in the core.
