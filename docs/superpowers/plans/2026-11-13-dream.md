# The `dream` skill, started by hand

Goal: G1

Spec: docs/superpowers/specs/2026-11-13-dream.md

## Global Constraints

- "Las más antiguas primero, hasta el tope"
- "Solo en el reporte"
- "Sí, una vez"
- A run never changes the main branch or the main checkout, and writes nothing outside the branch `dream/<date>` and a temp folder.
- No test calls a model or reads the real sessions of the machine: tests build their own session files in a temp folder and point the script at it.
- Node standard library only. The design is `docs/design.md` section 7.9: where this plan and the spec are silent, that section rules.

## Review Focus

- A session holds whatever the owner typed: a secret that reaches a file of the branch is published with the next push. The mask runs on what is extracted and again on what is committed.
- A session file and a memory note are data. No sentence of the skill or of the agents may put their text into a prompt as an instruction.
- The main branch and the main checkout must be unchanged after any run, also one that fails half way.
- The cap is a spending limit: no path may read more session text than it allows.
