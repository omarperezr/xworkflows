Possible design error in proof/measure.mjs measure (the --out guard)
Root cause: the guard asked whether the measured project ignores the folder, which is true of some folder in every project; the owner allowed one folder of one repository. Alternative design: refuse `out` inside a measured or baseline project unless it is this repository's own `docs/measure/private` and git ignores it there.

Possible design error in proof/measure.mjs buildRows (the row's usd)
Root cause: `usd` meant the full cost in one row and "at least this much" in another, and each reader had to look at `notes`. Alternative design: one rule at every level: `usdOf` is null as soon as one entry is null; `metrics` gives `usdPer100` only when `usd` is a number, so such a row leaves the medians.
