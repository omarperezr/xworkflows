# Hand-off at the end of each batch

Goal: G1

Spec: docs/superpowers/specs/2026-11-19-handoff.md

## Global Constraints

- "Apunta, no copia": the hand-off holds ids and paths, never the plan or the cards copied.
- Its own cap: `tokens.handoffBytes`, default 1500, outside `tokens.sessionStartBytes`.
- "Sí, automático": a plain `/compact` uses the hand-off with no pasting.
- "Texto para pegar": hosts with no session-start hook get the hand-off in the chat.
- "Skill handoff": no command named smart-compact.
